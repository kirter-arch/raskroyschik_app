# О проекте
Этот проект был создан, чтобы упростить и автоматизировать работу мастеров по тонировке. Больше не нужно делать раскрой вручную и тратить время на расчёты. С помощью этого приложения вы сможете:

  Точно и эффективно раскроить тонировочную плёнку для разных автомобилей.
  Вести базу клиентов, сохраняя их данные и историю заказов.
  Автоматически рассчитывать стоимость услуг.

Проект разработан на Python с использованием библиотеки Streamlit, что делает его простым и доступным для запуска.

# Возможности:

  Интуитивный интерфейс: Простой и понятный для любого пользователя.
  Функция раскроя: Введите размеры, и приложение предложит оптимальный вариант.
  База данных клиентов: Хранение информации о клиентах и их заказах.
  Калькуляция: Автоматический расчёт финальной стоимости.

# Как установить и запустить
Для запуска приложения на вашем компьютере вам понадобится Python 3.7 или выше.

1. Клонируйте репозиторий:
  git clone https://github.com/kirter-arch/raskroyschik_app.git
  cd raskroyschik_app
2. Cоздайте виртуальное окружение (рекомендуется):
  python -m venv venv
  #Для Windows
  venv\Scripts\activate
  #Для macOS/Linux
  source venv/bin/activate
3. Установите все зависимости:
  pip install -r requirements.txt
4. Запустите приложение:
  streamlit run app.py

Приложение откроется в вашем браузере по адресу http://localhost:8501.
